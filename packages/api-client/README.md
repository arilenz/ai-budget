# api-client

Typed API client. Two files:

- `src/schema.ts` — generated by `openapi-typescript` from `/openapi.yaml`. Do
  not edit by hand.
- `src/index.ts` — thin wrapper around `openapi-fetch` exposing
  `createApiClient({ baseUrl, getToken })`. The `getToken` callback is awaited
  on every request and injected as `Authorization: Bearer <token>`.

## Consumers

- `apps/web` imports via `#api-client` (Node subpath imports + tsconfig paths).
  Used **server-side only** — see `apps/web/src/lib/api-server.ts`.
- `apps/mobile` imports via Metro's `extraNodeModules` mapping. Used directly
  from RN code with a token from `expo-secure-store`.

There is no published npm package — consumers reference source files directly.

## Regeneration

Spec source of truth is `/openapi.yaml` at the repo root. Bump via:

```sh
# From repo root — dumps spec and regenerates schema.ts in one go
./scripts/generate-api-client.sh

# Or just the type-gen half, if openapi.yaml is already fresh
cd packages/api-client && npm run generate
```

`openapi-fetch` and `openapi-typescript` are the only deps.
